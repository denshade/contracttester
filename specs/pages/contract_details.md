On this page users can see the contract details. 
They can see name, the different versions and see if they have still active verifiers. 

There is a list of all active verifiers.

There is a list of all statements. 
A user can also see which verifier has verified which statement. with a last verified date.
Users can remove a contract. They are prompted if they are sure. 

Users can add statements to a contract. This contains a trigger(usually an URL), state and payload.
